# Chocolatey Community

This organization holds projects that are driven by the Chocolatey Community.

## These Are Not Chocolatey Software Products

Projects in this organization are community-driven. They are not products of Chocolatey Software, Inc., and they are not covered by any Chocolatey Software support agreement, SLA or security testing programme.

Chocolatey Software staff sometimes contribute to these projects to help keep them up to date, but that help is best effort and is not a commitment to maintain any project.

Chocolatey Software's own open-source products live in the [chocolatey](https://github.com/chocolatey) organization.

## Getting Help

- **Community projects in this organization:** open an issue on the relevant repository. Maintainers respond on a best-effort basis.
- **Chocolatey for Business customers:** use your normal Chocolatey Software support channel: run the `choco support` command for your options. Problems with community projects are not handled through commercial support.

## Reporting Security Issues

- **A vulnerability in a project in this organization:** report it privately using **Report a vulnerability** on that repository's **Security** tab. Please do not open a public issue.
- **A vulnerability in a Chocolatey Software product:** follow the [Chocolatey security disclosure process](https://docs.chocolatey.org/en-us/information/security).

If you are not sure which applies, for example an issue that appears through a community project but is caused by Chocolatey CLI, report it to the project and the maintainers will pass product issues on.

## Contributing

Contributions are welcome. See each repository's README for how to build and test it, and follow our [Code of Conduct](https://github.com/chocolatey-community/.github/blob/main/CODE_OF_CONDUCT.md).
